# FocusMusic

FocusMusic 是一个极简的专注计时网页应用：选择专注时长，开始计时；专注结束后进入休息，并播放本地音乐文件夹中的随机 mp3。音乐结束后，自动进入下一轮专注。

当前版本是纯前端实现，可以直接在浏览器中打开 `index.html` 使用。

## 功能

- 专注倒计时，默认 30 分钟。
- 预设时长：15 / 25 / 30 / 45 / 60 分钟。
- 支持自定义时长输入，范围为 1-120 分钟。
- 专注结束后随机播放本地音乐文件夹中的 mp3。
- 未选择音乐或文件夹中没有 mp3 时，默认进入 5 分钟休息。
- 音乐结束或默认休息结束后，自动进入下一轮专注。
- 休息中可点击「跳过」回到专注就绪状态。
- 专注中可点击「快进」直接进入休息，快进不计入专注时长。
- 自动记录每日专注时长。
- 提供月度统计视图，展示本月总分钟、专注天数和每日热力格子。
- 设置面板支持「音乐计入专注」开关和音乐文件夹选择入口。
- 倒计时基于真实时间计算，网页失焦或切到后台后不会变慢。

## 使用方式

1. 下载或克隆本仓库。
2. 在浏览器中打开 `index.html`。
3. 选择专注时长，点击开始。
4. 如需音乐休息，点击右上角齿轮，在设置面板中选择本地音乐文件夹。

浏览器出于安全限制，不会永久保存本地文件夹授权。刷新页面后，可能需要重新选择音乐文件夹。

## 数据存储

FocusMusic 使用浏览器本地存储保存：

- 每日专注记录
- 设置项状态

音乐文件不会上传，也不会离开本机。应用只在当前浏览器会话中读取你手动选择的本地文件夹。

## 本地测试

项目不依赖构建工具。已有逻辑测试可直接用 Node.js 运行：

```bash
node tests/timer.test.js
```

测试覆盖计时逻辑、后台真实时间计算、休息状态、专注记录、月度统计、设置存储和自定义时长等核心行为。

## 设计方向

界面目标是安静、克制、低干扰：

- 深色背景
- 巨大纤细的倒计时数字
- 极简图标按钮
- 设置和统计入口弱化处理
- 尽量减少非必要文字和装饰
